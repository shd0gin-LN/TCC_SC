O que é um Endereço IP?

O que é IP?

IP (Internet Protocol) é um número único que identifica um dispositivo na internet ou em uma rede local. Funciona como um “endereço residencial” digital.

IPv4 vs IPv6

IPv4: formato clássico (ex: 192.168.1.1)
IPv6: versão mais nova, com bem mais endereços disponíveis (ex: 2001:0db8:...)

IP Público x Privado

Público: visível na internet (o que este site mostra)
Privado: usado dentro da sua casa/empresa (ex: 192.168.x.x)

Para que serve?

Permite que sites, servidores e dispositivos se comuniquem. Também é usado para geolocalização aproximada, segurança e roteamento de dados.
